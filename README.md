# VerFruit

VerFruit is a responsive website developed for a fruit and vegetable store as part of the Codo a Codo course.

The project was built using HTML, CSS, and JavaScript, incorporating responsive design, forms, animations, and integration with an external API.

## Features

- Home page.
- About section.
- Product offers and prices.
- Recipes section.
- Contact form.
- Multi-page navigation.
- Responsive design.
- CSS animations.
- Dynamic content using JavaScript.
- External API integration.

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Animate.css
- Fetch API
- Mercado Libre API

## API Integration

The project consumes the Mercado Libre API using JavaScript and the `fetch` API.

The application processes the JSON response and dynamically updates the DOM with product information such as:

- Product name.
- Price.
- Product image.

This integration allowed the website to combine static HTML content with dynamically retrieved data.

## Responsive Design

The website uses CSS media queries to adapt its layout to different screen sizes.

Responsive behavior was implemented for:

- Desktop.
- Tablet.
- Mobile devices.
